# Cursor

Install with `--clients cursor` to link skills into `~/.cursor/skills`.
Invoke the skills from Cursor's skill menu or by name.
The portable installer does not overwrite Cursor rules or settings; reference this bundle's `agents.md` from your existing rules if desired.
Use available native agents with the shared reviewer prompt bodies; do not assume the Claude YAML agent definitions register here.
Cloud agents and third-party pstack ports are not prerequisites.
