# Pi

The installer links skills into `~/.pi/agent/skills` and rules into `~/.pi/agent/AGENTS.md`.
Use `/skill:zk-review`, `/skill:zk-fix`, or `/skill:team` when skill commands are enabled, or request the skill by name.
Delegation depends on installed extensions or an explicitly configured external runner.
Do not assume a built-in subagent tool.
Use the selected review prompt as a file reference for an available worker; otherwise perform the checks serially with an explicit independent-review gap.
